# Billetera Digital

Aplicación web de billetera digital desarrollada como parte de mi formación en desarrollo Full Stack Python.

El proyecto permite trabajar distintas funcionalidades de una billetera digital, mediante una interfaz desarrollada con HTML, Bootstrap, JavaScript y jQuery.

## Funcionalidades

- Inicio de sesión.
- Consulta y actualización de saldo.
- Depósito de dinero.
- Envío de dinero.
- Visualización de movimientos.
- Manejo de información mediante JavaScript y jQuery.
- Actualización dinámica de elementos de la interfaz.

## Tecnologías utilizadas

- HTML
- Bootstrap
- JavaScript
- jQuery
- localStorage
